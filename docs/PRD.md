# 產品需求文件 (PRD)：生活目標追蹤與打怪系統

## 1. 專案概述

### 背景與動機
傳統的待辦清單或打卡工具雖能記錄進度，但缺乏趣味性與成就感，容易讓使用者失去興趣。因此，本專案希望結合遊戲化設計，將日常任務轉換為「打怪升級」的形式，讓使用者在完成目標的同時獲得成就與樂趣。

### 目標用戶
1. 高中生、大學生
2. 想培養自律習慣的人
3. 容易拖延、缺乏動力的族群
4. 喜歡遊戲或視覺化回饋使用者

### 核心價值主張
透過遊戲化的設計（打怪、升級、獲得獎勵），將枯燥的日常任務轉化為有趣的挑戰，幫助使用者建立並維持良好的習慣，克服拖延症，並在過程中獲得持續的成就感。

---

## 2. 功能需求

### 主要功能清單
1. **每日任務自動重置**：系統每天固定時間（如凌晨 00:00）自動將所有每日任務恢復成「未完成」狀態。
2. **任務進度清空**：將玩家前一天的任務完成進度歸零，例如「已打怪 3/5」會重新變成「0/5」。
3. **每日任務刷新**：系統重新隨機產生或更新新的每日任務內容，例如從「完成1次登入」變成「擊敗3隻怪物」。
4. **重置通知提醒**：任務更新後跳出提示訊息，例如「每日任務已刷新！」提醒玩家查看新任務。
5. **任務獎勵重新領取**：重置後玩家可以再次完成每日任務並重新獲得對應獎勵（經驗值、金幣等）。

### 使用者故事 (User Stories)

* **功能 1：每日任務自動重置**
  * 作為 **玩家**，我希望 **系統每天固定時間自動重置任務**，以便 **我每天都有新的開始和挑戰可以進行**。
* **功能 2：任務進度清空**
  * 作為 **玩家**，我希望 **未完成的進度在隔天歸零**，以便 **我能清楚知道今天是全新的一天，不會被昨天的未完成項目干擾**。
* **功能 3：每日任務刷新**
  * 作為 **玩家**，我希望 **每天登入時能看到隨機或更新的任務內容**，以便 **保持新鮮感，不會因為每天做一模一樣的事而感到厭煩**。
* **功能 4：重置通知提醒**
  * 作為 **玩家**，我希望 **在任務更新後能收到提示訊息**，以便 **我能及時知道可以開始進行新的每日任務**。
* **功能 5：任務獎勵重新領取**
  * 作為 **玩家**，我希望 **完成重置後的任務可以再次獲得經驗值與金幣**，以便 **我能持續累積資源來升級角色或購買道具**。

## 3. 非功能需求

### 技術限制
* **後端框架**：使用 Python Flask
* **前端樣板**：使用 Jinja2
* **資料庫**：使用 SQLite

### 效能與安全考量
* **效能**：系統需能準確且輕量地處理「跨日重置」的邏輯（例如在使用者第一次登入時計算時間差，或使用排程工具），避免造成伺服器過大負擔。
* **安全**：
  * 防止使用者惡意修改系統時間來重複領取每日任務獎勵。
  * 基本的密碼雜湊加密與使用者 Session 管理，防止未授權的資料存取。

## 4. MVP 範圍 (Minimum Viable Product)

### Must Have (必須要有)
* 建立基礎任務系統（新增、完成任務）。
* 角色等級與經驗值系統（完成任務可獲得經驗值並升級）。
* 每日任務自動重置與進度清空機制（跨日判定）。
* 任務完成後的獎勵發放機制（經驗值/金幣）。

### Should Have (應該要有)
* 每日任務刷新功能（從題庫中隨機抽出每日任務）。
* 簡單的怪獸與戰鬥視覺化呈現（打勾任務等於攻擊怪獸扣血）。
* 任務更新的重置通知提醒。

### Nice to Have (有的話會更好)
* 金幣商店系統（可以使用金幣購買虛擬道具或角色外觀）。
* 任務難度分級（不同難度的任務給予不同經驗值/金幣）。
* 歷史數據統計與圖表（查看過去一週/一個月的習慣完成率）。
