## 2. 功能需求

以下為系統的主要功能：

1. **目標與任務管理系統**：建立一個可設定並追蹤生活目標（每日、每週或單次任務）的系統。
2. **打怪與升級機制**：透過完成任務對怪物造成傷害或獲得經驗值，以此機制提升使用者動機。
3. **視覺化回饋與角色狀態**：提供直觀的視覺化回饋（如角色/怪物血條、經驗值條、等級顯示）增加成就感。
4. **獎勵與裝備/商城系統**：完成任務可獲得虛擬金幣，可用於購買裝備、角色外觀或道具。
5. **數據統計與回顧**：提供圖表顯示過去的任務達成率、習慣連續天數及角色成長歷程。

### 使用者故事 (User Stories)

- **目標與任務管理系統**
  - 作為一名使用者，我希望「能夠新增、編輯和刪除每日/每週的生活目標」，以便「我可以根據實際狀況安排我的計畫」。
  - 作為一名使用者，我希望「能將任務標記為完成」，以便「記錄我的努力成果」。
- **打怪與升級機制**
  - 作為一名使用者，我希望「完成任務時能夠獲得經驗值並升級」，以便「感受到自己的成長與進步」。
  - 作為一名喜歡遊戲的使用者，我希望「完成任務能對虛擬怪物造成傷害並擊敗牠們」，以便「讓無聊的待辦事項變得有趣」。
- **視覺化回饋與角色狀態**
  - 作為一名缺乏動力的族群，我希望「在介面上清楚看到角色的經驗條和怪物的血條」，以便「獲得即時的回饋與成就感」。
- **獎勵與裝備/商城系統**
  - 作為一名喜歡收集的玩家，我希望「能用完成任務獲得的金幣購買裝備或造型」，以便「客製化我的角色並擁有長期目標」。
- **數據統計與回顧**
  - 作為一名想培養自律習慣的人，我希望「能查看過去一週的任務達成率」，以便「了解自己的執行狀況並進行調整」。
在日常生活中，許多人會設定目標或列出待辦清單，但傳統的工具往往過於枯燥，缺乏即時的反饋與成就感，導致使用者容易半途而廢。本專案旨在將「自我管理」與「RPG 遊戲元素」結合，將抽象的目標具象化為需要挑戰的「怪物」。透過完成任務來扣除怪物血量、獲取經驗值與獎勵，讓提升自律的過程像在玩遊戲一樣有趣。

### 目標用戶
- **高中生與大學生**：習慣遊戲邏輯，需要動力來完成學業任務。
- **自律初學者**：想培養習慣但容易覺得挫折的人。
- **拖延症患者**：需要「即時反饋」來對抗拖延行為。
- **RPG 遊戲愛好者**：喜歡升級與收集要素的人。

### 核心價值主張
「將每一項任務，都變成一次冒險。」——讓枯燥的日常事務，轉化為熱血的升級之路。

## 2. 功能需求

### 主要功能清單
1. **每日任務自動重置**：系統每天固定時間（如凌晨 00:00）自動將所有每日任務恢復成「未完成」狀態。
2. **任務進度清空**：將玩家前一天的任務完成進度歸零，例如「已打怪 3/5」會重新變成「0/5」。
3. **每日任務刷新**：系統重新隨機產生或更新新的每日任務內容，例如從「完成1次登入」變成「擊敗3隻怪物」。
4. **重置通知提醒**：任務更新後跳出提示訊息，例如「每日任務已刷新！」提醒玩家查看新任務。
5. **任務獎勵重新領取**：重置後玩家可以再次完成每日任務並重新獲得對應獎勵（經驗值、金幣等）。

### 使用者故事 (User Stories)

* **功能 1：每日任務自動重置**
  * 作為 **玩家**，我希望 **系統每天固定時間自動重置任務**，以便 **我每天都有新的開始和挑戰可以進行**。
* **功能 2：任務進度清空**
  * 作為 **玩家**，我希望 **未完成的進度在隔天歸零**，以便 **我能清楚知道今天是全新的一天，不會被昨天的未完成項目干擾**。
* **功能 3：每日任務刷新**
  * 作為 **玩家**，我希望 **每天登入時能看到隨機或更新的任務內容**，以便 **保持新鮮感，不會因為每天做一模一樣的事而感到厭煩**。
* **功能 4：重置通知提醒**
  * 作為 **玩家**，我希望 **在任務更新後能收到提示訊息**，以便 **我能及時知道可以開始進行新的每日任務**。
* **功能 5：任務獎勵重新領取**
  * 作為 **玩家**，我希望 **完成重置後的任務可以再次獲得經驗值與金幣**，以便 **我能持續累積資源來升級角色或購買道具**。
### 2.1 核心功能列表
1. **成就解鎖功能**：完成指定條件後自動解鎖成就。
2. **成就進度追蹤功能**：顯示目前完成進度，例如 50/100。
3. **成就獎勵發放功能**：達成成就後發送金幣、道具或稱號獎勵。
4. **成就展示功能**：顯示玩家已獲得的徽章、稱號與完成紀錄。
5. **成就排行榜功能**：依成就數量或稀有度排名，增加競爭性。

### 2.2 使用者故事 (User Stories)
- **成就解鎖功能**：作為**玩家（使用者）**，我希望**當我完成特定次數的任務（如連續早起 7 天）時能自動解鎖對應成就**，以便**獲得破關的成就感**。
- **成就進度追蹤功能**：作為**玩家**，我希望**能夠清楚看到我目前離下一個成就還有多遠（如累積背單字 50/100 個）**，以便**我有明確的短期目標繼續努力**。
- **成就獎勵發放功能**：作為**玩家**，我希望**在達成成就後能獲得虛擬金幣或稀有稱號**，以便**我能在系統中購買虛擬道具或展示我的獨特身分**。
- **成就展示功能**：作為**玩家**，我希望**有一個專屬的成就牆或個人頁面，可以展示我所有收集到的徽章與稱號**，以便**回顧我的努力成果並獲得滿足感**。
- **成就排行榜功能**：作為**好勝的玩家**，我希望**能看到全伺服器或好友間的成就數量與稀有度排名**，以便**激發我的競爭心，讓我更有動力去解鎖更多成就**。
### 2.1 升級與稱號系統
- **使用者故事**：作為一名使用者，我希望在完成任務後能夠獲得經驗值（EXP），以便讓我感受到成長的即時回饋。
- **使用者故事**：作為一名使用者，我希望累積足夠經驗值後能提升等級並解鎖新稱號，以便滿足成就感。

### 2.2 任務與打怪管理系統
- **使用者故事**：作為一名使用者，我希望可以新增、編輯、刪除日常目標（任務），以便追蹤我每天需要做的事情。
- **使用者故事**：作為一名使用者，我希望將任務標記為完成時，能對應到對怪物的「攻擊」行為，以便讓枯燥的打卡變成有趣的戰鬥過程。

### 2.3 怪物系統
- **使用者故事**：作為一名使用者，我希望系統每天或每週會出現不同的怪物，以便保持新鮮感與挑戰性。
- **使用者故事**：作為一名使用者，我希望能夠擊敗不同的怪物並解鎖怪物圖鑑，以便收集成就。

### 2.4 數據統計與回顧
- **使用者故事**：作為一名使用者，我希望可以查看我過去一週或一個月的任務完成率與打怪紀錄，以便了解自己的執行狀況並進行調整。

### 2.5 裝備與獎勵系統
- **使用者故事**：作為一名使用者，我希望打倒怪物或連續完成任務可以獲得虛擬金幣或寶箱，以便兌換不同的裝備或自訂角色外觀。

## 3. 非功能需求

### 技術限制
* **後端框架**：使用 Python Flask
* **前端樣板**：使用 Jinja2
* **資料庫**：使用 SQLite

### 效能與安全考量
* **效能**：系統需能準確且輕量地處理「跨日重置」的邏輯（例如在使用者第一次登入時計算時間差，或使用排程工具），避免造成伺服器過大負擔。
* **安全**：
  * 防止使用者惡意修改系統時間來重複領取每日任務獎勵。
  * 基本的密碼雜湊加密與使用者 Session 管理，防止未授權的資料存取。
### 3.1 技術限制
- **框架限制**：使用 Python + Flask 作為後端框架，搭配 Jinja2 作為模板引擎。
- **資料庫**：使用 SQLite 儲存使用者資料、任務與遊戲進度。
- **前端**：使用 HTML, CSS, JavaScript，強調動態回饋與遊戲化視覺效果。

### 3.2 效能與安全考量
- 系統應確保使用者的任務資料與遊戲進度正確儲存且具備一致性，避免資料遺失。
- 需具備基本的使用者註冊、登入與認證機制，確保個人資料隱私與安全（使用者僅能看到自己的任務與進度）。
- 網頁回應速度應快速，以保持流暢的互動體驗。

## 3. 非功能需求

### 3.1 技術限制
- **後端框架**：使用 Python 的 Flask 框架。
- **前端渲染**：使用 Jinja2 模板引擎進行伺服器端渲染 (SSR)。
- **資料庫**：使用 SQLite 作為關聯式資料庫，方便輕量化部署與開發。

### 3.2 效能與安全考量
- **效能**：排行榜功能若資料量大，查詢需進行優化（例如加入索引），確保頁面載入時間在合理範圍內（< 2 秒）。
- **安全**：
  - 密碼需進行雜湊（Hash）加密儲存（如使用 bcrypt）。
  - 防止 SQL Injection（使用 ORM 或參數化查詢）。
  - 防止 XSS 攻擊（Jinja2 預設會進行 HTML 跳脫）。
  - 任務完成與成就解鎖的 API 需有防呆防刷機制（例如限制短時間內的異常連續請求）。

# PRD — 生活目標加打怪系統

## 1. 專案概述
- **背景與動機**：傳統的代辦清單或打卡工具雖能記錄進度，但缺乏趣味性與成就感，容易讓使用者失去興趣。因此，本專題希望結合遊戲化設計，將日常任務轉換為「打怪升級」的形式，讓使用者在完成目標的同時獲得成就與興趣。
- **目標用戶**：高中生、大學生。這群用戶面臨課業、社團與生活瑣事等多重壓力，需要有趣的方式來激勵自己完成日常任務。
- **核心價值主張**：將無聊的日常代辦事項遊戲化，透過打怪、升級與獎勵機制，提升用戶完成目標的動力與樂趣。

## 2. 功能需求
1. **任務建立與管理**
   - 作為 **高中生/大學生**，我希望 **能夠輕鬆建立並編輯我的日常任務清單**，以便 **我能清楚掌握每天要完成的事情**。
2. **任務完成與打怪機制**
   - 作為 **玩家（使用者）**，我希望 **在勾選完成任務時能看到角色攻擊怪物並獲得經驗值**，以便 **我能感受到努力的實質回饋與成就感**。
3. **角色升級與數值系統**
   - 作為 **玩家（使用者）**，我希望 **我的角色能夠隨經驗值累積而升級變強**，以便 **我有持續完成任務的長期動力**。
4. **怪物系統與關卡**
   - 作為 **玩家（使用者）**，我希望 **能挑戰不同種類與難度的怪物**，以便 **保持遊戲的挑戰性與新鮮感**。
5. **成就展示與獎勵**
   - 作為 **收集控玩家**，我希望 **能解鎖成就或獲得特殊稱號**，以便 **我能展示我的努力成果並滿足收集慾望**。

## 3. 非功能需求
- **技術限制**：系統基於 Web 技術開發，使用 Flask 作為後端框架，搭配 Jinja2 模板引擎進行前端渲染，並採用 SQLite 作為關聯式資料庫儲存資料。
- **效能與安全考量**：
  - **效能**：頁面載入與操作回應時間需快速順暢，確保打怪回饋即時。
  - **安全性**：使用者密碼需經過加密儲存（如 bcrypt），並實作基本的權限控管與防護（防止 SQL Injection 與 XSS），確保每位使用者只能存取自己的任務與角色資料。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須有)**：
  - 使用者註冊、登入與登出系統。
  - 任務清單的 CRUD（新增、讀取、更新、刪除）。
  - 點擊完成任務能扣除怪物血量並獲得經驗值。
  - 基礎的角色狀態顯示（等級、經驗值條、當前遭遇的怪物）。
- **Should Have (應該有)**：
  - 任務難易度分類，不同難度給予不同經驗值。
  - 怪物連續推進機制（怪物死亡後出現下一隻）。
  - 簡單的打怪視覺回饋或動畫效果。
- **Nice to Have (可以有)**：
  - 金幣商城系統與裝備道具購買。
  - 角色外觀客製化。
  - 朋友排行榜或社交分享功能。
